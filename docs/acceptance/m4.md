## Full workflow: core2 → refine a strait → hand-fix coastal nodes → save

**1. Local refinement of the Denmark Strait** (API, box
`[-32..-20]×[64.5..69.5]`, target 55 km, RTopo coastal land cut):

- job finished in ~2 s; **watertight seam** (71 seam edges), 107 new
  interior nodes, interior median 44.0 km, min angle 32.9° (median 48.3°);
- 126,858 → 126,564 nodes (the RTopo land cut re-ran inside the cavity with
  the seam protected — finer coastline eats some old near-coast nodes);
- refined mesh auto-registered (`m2`, name `core2_strait55`).

**2. Browser edit session on the refined mesh** (`/?mesh=m2`, map view,
figures `m4-ui-selection.png` / `m4-ui-after-edit.png` / `m4-ui-saved.png`;
the low HUD fps in the figures is headless SwiftShader rendering, not GPU):

- `[E]` opened a live edit session (`session open · 126,564 nodes`);
- **brush** (120 km) stroked along the strait selected **27 nodes**
  incl. coastal ones — orange tint + selection dots visible in the figure;
- **drag** (~20 km tangent-plane move from a selected node) committed as a
  journaled move op: `moved 27 nodes · min angle 41.2°→21.2°` — the
  quality delta the panel is there to surface;
- **smooth selection** (2 iterations, strength 0.5): `smoothed 21 nodes`
  — the 6 mesh-boundary (coast) nodes in the selection stayed anchored by
  design, unselected neighbours acted as anchors;
- **undo / redo** via ⌘Z / ⇧⌘Z round-tripped the smooth
  (`undid last op` / `redid last op`, buttons tracking journal state);
- **save-as** wrote the FESOM2 triplet + `edits.jsonl` and auto-registered
  the result (`saved → …/core2_strait55_edited (mesh m3, journal
  included)`).

**3. Saved artifacts validated** (runner, bit-exact):

- triplet reads back clean (126,564 nodes / 244,090 elements);
- journal holds exactly the 2 active ops (move + smooth; the undo/redo
  markers replay correctly);
- **`apply_journal` on the pristine refined mesh reproduces the saved mesh
  hash bit-exact** — the M4 reproducibility guarantee, resting on the
  shortest-repr FESOM ASCII writer + round-trip reader.
